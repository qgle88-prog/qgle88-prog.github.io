## 说明

下载区里放的是**整理好、有说明、能直接给别人用**的东西。

但日常写的脚本里，有相当一部分属于「自己用刚好，给别人用还差一层包装」——
少一个 README、参数写死了路径、或者依赖某个只有我这儿才有的目录结构。

这些我没往下载区放，因为放上去大概率是给人添麻烦。它们都在 GitHub 上，
有兴趣的话可以自己翻。

## 什么时候会整理上来

看情况，大致是这两类：

- 有第二个人问「这个能不能给我用一下」的时候
- 我自己隔了几个月还要回头改的时候——说明它已经稳定到值得写文档了
